## 要制作的动画

1. 创建可编辑的 Spine 工程，按散件说明组装机身、膜卷、膜、封头、夹环和遮挡层。保持素材之间的原始对齐；允许纹理打包时裁透明边，但要保证原位置和轴心不变。
2. 制作 `idle`：机器处于待机初始状态，不循环播放封口动作。
3. 制作 `seal`：以约 1 秒、30 fps 为目标，依次完成夹环闭合、送膜、封头下压、停留热封、封头抬起、夹环打开。建议帧位参照原 README；可根据实际观感微调，但不要打乱工序。`seal` 播放一次后应回到适合 `idle` 的状态。
4. 膜卷使用 `roll_00`～`05` 和 `film_00`～`05` 同步切换，避免把整张膜卷图片当成平面直接旋转。封头以上下移动为主，不旋转。
5. 夹环优先采用 README 的游戏推荐方案：后半环、杯子、前夹爪分层；不要同时叠加 `clamp_full`。`clamp_front_00` 为透明帧，可用无附件表示。

## 杯子与遮挡：必须验证

游戏中的杯子不能只是 Spine 内一张固定图片：玩家制作的不同饮品需要继续由游戏杯子节点显示。请实际验证杯子在**后半环前、前夹爪及封头后**的遮挡关系。

先确认本机 Spine 与 Cocos 的具体挂点／渲染能力，再选择可行方案，例如游戏节点挂载到可用的骨骼挂点，或把机器拆为前后渲染层。交付中说明具体节点、插槽、层级、坐标换算和播放同步方式。不要仅凭编辑器里放一张示意杯图就声称游戏遮挡已完成；如果只能在 Spine 中预览，请明确写出未验证的 Cocos 集成步骤和限制。
