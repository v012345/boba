# 垃圾桶动画散图 v2：透视修正版

共 7 张 1280×1280 透明 PNG：body.png，以及 lid_00_closed 到 lid_05_open 六帧。没有覆盖 v1，也没有修改脚本、场景或 Spine 文件。

本版修正：打开时盖子不再突然变宽，微开帧去除第二层盖板，统一较薄的盖沿；调整从顶面到内侧面的角度变化。桶身沿用 v1，盖子使用内置 image_gen 重新补绘，随后拆图、对齐。

所有散图按同一画布中心叠放，body 在下、lid 在上；保留透明留白。铰链中心参考为左上角坐标 (640,500)，相对画布中心约 (0,+140)，后者 Y 朝上。开盖 00→05，关盖倒序。建议先看动图再配合桶身果冻形变调整时序。

这是手绘动画帧，并非严格三维模型投影，少量纹理和铰链细节差异仍需在最终动画中验收。

预览文件（仅供查看，不是游戏用图集）：
- output/bin-animation-v2/preview.png：六帧叠加预览。
- output/bin-animation-v2/open-close.gif：慢速开关盖循环。
- output/bin-animation-v2/prompts.json：生成提示词与处理记录。
