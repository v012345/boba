# 垃圾桶分层散图 v1

交付内容：1 张桶身 + 6 张桶盖，均为 1280×1280 RGBA 透明 PNG，不是图集。

- body.png：独立桶身，保留完整桶口，没有盖子。
- lid_00_closed.png：关闭。
- lid_01_slight.png：微开。
- lid_02_small.png：小半开。
- lid_03_half.png：半开。
- lid_04_wide.png：大半开。
- lid_05_open.png：全开。

桶身置于底层，桶盖置于上层。所有图片使用相同画布中心对齐；不要逐张裁去透明留白后再直接居中。后铰链参考点约为图片左上角坐标 (640, 500)，即相对于画布中心的 (0, +140)，后者 Y 向上。

开盖顺序 00 → 05，关盖倒序。可先试每帧 0.05 秒，总开盖约 0.3 秒，再按桶身的果冻动作调整。桶身形变时注意盖子铰链也应随桶口移动。

素材沿用原垃圾桶风格，用内置 image_gen 分别补绘并进行画布、铰链对齐整理。手绘帧之间仍有细节变化，需在你实际动画中验收；并非三维模型严格投影。

叠加预览：项目根目录 output/bin-animation/preview.png，仅供查看，不作为动画图集使用。
生成提示词：output/bin-animation/prompts.json。
本次未修改游戏脚本、场景或已有 Spine 文件，也未覆盖旧垃圾桶素材。
