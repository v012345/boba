## 奶茶铺拖动手感重修（assets/scripts/TeaShop.ts, TeaDropTargets.ts, TeaGame.ts）

问题：杯子放上制作台后经常拖不动。

根因（三个叠加）：
1. 旧抓取热区只有一个 190×190（约杯子 1.4 倍），手机上比手指还小，点位必须很准。
2. 该热区每帧被 `syncCupTouch` 改位置、改尺寸、改 active；`placing`（0.45s 滑入）与 `sealing` 期间直接 `active=false`，按在“杯子落点”上必然打空。
3. 若手指移出小热区，手势可能断开（原作者用「抓起后扩成全屏」规避，但每帧又缩回去）。

改法：
- 两块**固定**抓取面：StationGrab(-115,-96,250×200)、MachineGrab(125,-100,200×190)，位置尺寸永不逐帧变化，只随 `canAct()` 切 active，且拖动中不改 active。
- 按下时按杯子中心做矩形近似容差判定（半宽 70*scale + 60），所以压块重叠也不会互相抢。
- 抓到后把命中的那块临时扩成 1280×720 并置顶，松手 `resetGrip()` 还原，保证手势不丢。
- `placing` 期间按住 → `TeaGame.settlePlacement(0)` 立即完成滑入并开拖。
- 手感：上抬 26px + 放大到 1.08 缓入（grip 累积），落点以杯心（含上抬）判定；抓起即画出全部可放置区，悬停高亮（`hoverKey` 变化才重绘 Graphics）；封盖机/垃圾桶支持 52px 近似命中（`findSnapTarget`），客人必须精确命中防错单；未命中 0.16s 三次方缓出飞回原位，不再瞬移；位移 <8px 视为点击，不弹提示。
- 删掉 `cupTouch` / `syncCupTouch` / 每帧 `setSiblingIndex`。

测试：20 项通过（新增 settlePlacement、findSnapTarget/dropZones 用例），`tsc --noEmit --skipLibCheck --ignoreDeprecations 6.0` 通过。未在 Creator / 真机验收触控。

## web-mobile 横屏守卫

结论：**网页无法强制横屏**（iOS Safari 连 `screen.orientation.lock()` 都没有），所以做「竖屏拦截 + 能锁就锁」。

`TeaShop.ts`：
- `viewportSize()`：web 取 `window.innerWidth/innerHeight`，原生退回 `engineScreen.windowSize`（`view.getFrameSize()` 自 3.4 起已废弃）。
- `checkOrientation()`：宽 < 高×1.02 即视为竖屏；事件驱动（window resize / orientationchange）+ update 里 0.4s 轮询兜底 + 旋转后 180ms 复检（有的浏览器延迟一两帧才更新）。
- 竖屏 → `cancelDrag()` + `showRotateHint()`（1280×720 遮罩 + `BlockInputEvents` + 卡片），`update` 直接 return → **计时和动画一起冻结**，`canAct()` 也加了 `!portrait`。
- 卡片按钮「全屏并锁定横屏」：`requestFullscreen()` → 成功后 `screen.orientation.lock('landscape')`，catch 吞掉。iOS 无 lock 时**不显示按钮**，改显示手动旋转提示，避免死按钮。
- `onDestroy` 解绑 window 监听。

页面级（需覆盖 index.html，见 README）：`screen-orientation` / `x5-orientation` / `x5-fullscreen` / `full-screen` 四个 meta；PWA 用 manifest `"orientation": "landscape"`。**不要手写整个 index.html**（引擎脚本名抄错即黑屏），从一次构建产物复制到 `build-templates/web-mobile/` 再改。

顺带确认：Creator 3.8.8 的 web 模板在 app.asar 里是加密 .ccc，无法直接解出；asar 头格式为 [u32=4][headerSize][?][jsonSize][json]，文件基址 = 8+headerSize 4 字节对齐。

## GitHub Pages 白屏（已修复）

线上 https://v012345.github.io/ ，仓库 `~/Desktop/work/v012345.github.io`，Pages 源 = master 根目录。

修复：仓库根加空 `.nojekyll`，commit `c601a36` 已推送，约 30s 后 Pages 重建完成。
